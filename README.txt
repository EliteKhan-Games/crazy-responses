CRAZY RESPONSES — WILDER PROMPT UPDATE

WHAT THIS CHANGES
- Makes the prompt sentences much more absurd, chaotic, and surreal.
- Adds bizarre locations, characters, objects, and scenarios.
- Keeps Comedy, Chaotic, and Mixed styles.
- Produces a fresh combination whenever the existing game functions request a prompt.

INSTALL
1. Open your EXISTING Supabase project > SQL Editor.
2. Select New query.
3. Open supabase-wilder-prompts-fix.sql and copy the entire file.
4. Run it once.
5. The query result previews six new prompt examples.

IMPORTANT
- Do NOT delete your old SQL queries, tables, or functions.
- Do NOT rerun the original full database migration.
- This update replaces ONLY public.cr_generate_prompt(text).
- It does not change timers, voting, room browser, room creation, scores, or leaderboard.
- No app.js, index.html, styles.css, or config.js changes are needed.
- This is randomized template-based prompt generation, not an AI service.
